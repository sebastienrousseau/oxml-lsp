# oxml-lsp 0.0.11

Release preparation dated 2026-10-17. This file does not announce a
publication or authorize a tag.

## Highlights ⭐️

* **Bounded editor input**: Cap protocol headers at 8 KiB and bodies at 16 MiB before body allocation, and use strict core parsing.
* **Bounded CLI input**: Stop file/stdin reads at the 8 MiB document budget without waiting for an untrusted stream to close.
* **Lockstep integration**: Require oxml and oxml-json =0.0.11 and retain shared JSON framing rather than another private parser.

## Upgrade notes

Rust 1.89.0 or newer is required. The publishable family packages share
version 0.0.11; unpublished fuzz/conformance harnesses use 0.0.0.
Inputs exceeding the documented application budgets return errors.

## Verification and release status

Publish and index oxml and oxml-json 0.0.11 before registry-only validation.
Local family-source overlays verify integration but do not prove that a
version exists on crates.io or that registry-only lockfiles can resolve.
Regenerate and verify registry locks after the prerequisites are indexed.

The final source commit must pass the repository gate and published PR

before authorizing publication. The release page's change list and
